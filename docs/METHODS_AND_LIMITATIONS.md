# Methods, results, advantages, and limitations

This note explains what was actually tried, what each change was meant to do, and what the saved results do and do not support. The detailed values and run status are in [the experiment ledger](RESULTS.md).

## 1. Problem and baseline

The task is seven-class classification of potato-leaf disease images from the Mendeley *Potato Leaf Disease Dataset in Uncontrolled Environment*. The fixed evaluation manifest contains 2,492 training, 276 validation, and 308 test images. The compact student is a 1.051M-parameter hybrid CNN with about 0.630 GFLOPs at 224×224. The ResNet18 teacher has about 11.276M parameters and 1.818 GFLOPs at 224×224.

The paper uses online distillation: teacher and student are updated sequentially within each training step. Most local “best student” runs instead train a teacher first, freeze it, and then distill the student (offline KD). The deployment student architecture and 224 resolution are matched, but those training protocols are not identical. The paper reports 84.57% student Accuracy; the local baseline checkpoint reports 84.09% Accuracy. Its Macro-F1 is disputed between two saved evaluators, 82.65% and 81.61%, so exact F1 gains over baseline are not yet settled.

## 3. What the combined results support

1. **The confidence-adaptive proposal did not improve the tested baseline.** Its value as a research hypothesis remains, but the current result is negative.
2. **The strongest fixed-split result is a recipe-level gain, not an isolated adaptive-loss gain.** Optimizer/schedule, augmentation, EMA, label smoothing, teacher protocol, and training length changed across the path to the 89.83% three-seed student.
3. **Short loss ablations suggest KD terms may help a baseline-initialized student**, especially response DKD in the tested short setup, but those runs do not settle the best loss or weights.
4. **A higher-resolution teacher improves teacher-side scores at increased FLOPs.** The corresponding 256-pixel warm-start student result also changes several factors and should be treated as exploratory.
5. **MixUp was negative and class weighting showed a one-run Accuracy/Macro-F1 trade-off.** Neither result is multi-seed evidence.
6. **An ensemble of teachers is not automatically a better student target.** The recorded student difference is small, on another split, and at extra teacher-training cost.

## 4. Dataset and method caveats

- The fixed split has 308 test images; one prediction changes Accuracy by approximately 0.325 percentage points.
- The local MD5 audit found exact duplicate files crossing the fixed split (17 test files with identical copies in train/validation). This is a data-split concern. MD5 does not find visual near-duplicates.
- One early notebook used 2,487/274/315; those values are quarantined in the ledger and are not mixed with fixed-split values.
- A reported four-fold procedure repeatedly evaluated the same held-out test set. It is not a conventional independent cross-validation estimate.
- A paper comparison must state the protocol change: the local main student uses a separately trained frozen teacher (offline KD); the paper's baseline is online KD.
- Macro-F1 on the local paper checkpoint is disputed between the run JSON and a later evaluation script. Resolve it by evaluating a single saved checkpoint with one canonical metric implementation before calculating exact F1 gains.

## 5. Reporting recommendation

For a defensible presentation, report the paper number and the local baseline as separate references; lead with the 3-seed scratch student and its mean ± sample SD; state the offline-KD and recipe changes; place adaptive confidence KD and MixUp under negative findings; show class-weighting as a one-seed trade-off; move 384 resolution, warm-start, TTA/calibration, and multi-teacher experiments to separate ablation/trade-off tables. Include the duplicate audit and avoid asserting the test score is an unbiased estimate of performance on new farms or devices.
